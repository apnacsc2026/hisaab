Data kahan save karein?

☁ Google Drive (kahin se bhi, phone par bhi)

Data aapke apne Google Drive me save hota hai. Computer aur phone dono par wahi data khulega. Is app ke server par kuch nahi rehta.

💾 Computer ka folder

Naya folder banao (jaise D:\CSC-Data) aur use chuno. Desktop, Documents ya Downloads folder seedha na chunein, unke andar ka koi folder chunein. Purana data chahiye to wahi purana folder chuno. Ye sirf computer ke Chrome / Edge me chalta hai.
