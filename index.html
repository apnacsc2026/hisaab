Where should your data be saved?

☁ Google Drive (from anywhere, including your phone)

Your data is saved in your own Google Drive. The same data opens on both computer and phone. Nothing is stored on this app\'s server.

💾 Computer folder

Create a new folder (for example D:\CSC-Data) and select it. Do not select the Desktop, Documents or Downloads folder itself; pick a folder inside them. To use your old data, select the same old folder. This works only in Chrome / Edge on a computer.
